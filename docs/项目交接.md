## 五、环境与关键技术结论

- 本机已安装（可继续打包）：Rust 1.98.0、MSVC Build Tools(14.44)、Windows SDK 10.0.26100、Tauri CLI 2.11.4、Node v24.18.0/npm 11.16、WebView2 Runtime 151
- Tauri v2 注意事项：
  - `cargo tauri build` 默认即 release，不要加 `--release`（会报 unexpected argument）
  - tauri.conf.json / capabilities 不能带 UTF-8 BOM（serde_json 解析失败，必须无 BOM）

- exe 与 HTML 数据不互通：exe 数据存 WebView2 用户数据目录，HTML 存浏览器 localStorage，迁移必须走 JSON 导出导入
